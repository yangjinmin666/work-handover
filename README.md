## 资料维护约定

- 一份飞书文档对应一条索引，记录标题、用途、链接和访问状态。
- 飞书文档的访问权限以飞书设置为准；在此收录链接不改变原文档权限。
- 仓库可公开访问，收录的正文须已确认可以公开；账号权限仅记录申请方式，不填写密码或密钥。
- 代码以项目清单中的源仓库为准，本仓库用于集中说明和导航。
- 未确认的负责人、进度和结论写“待确认”；完成交接须有接手人的实际验证记录。
